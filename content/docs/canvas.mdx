---
title: The canvas
description: Move, group, and arrange nodes on the infinite canvas — pan, zoom, select, and the right-click menu.
---

The canvas is the heart of termsprawl: an infinite dot-grid surface where every
terminal, note, editor, and agent is a node you place exactly where you want
it.

## Pan and zoom

- **Pan** — drag the empty canvas, or scroll. 
- **Zoom** — use the on-screen zoom controls (bottom-left), or pinch on a
  trackpad. The range runs from **0.05×** — far enough out to see the shape of
  a very large layout — up to **3×**.
- **Fit view** — the canvas starts fitted to your nodes; use the controls to
  refit at any time.
- **Mini-map** — a small map of the whole canvas lives in the corner for
  jumping around a large layout.

## Move nodes

Drag any node by its **header** (a bar at the top of the node). The empty
canvas pans independently, so you can pull a node anywhere.

<Callout type="warn" title="Don't drag a terminal by its body">
  Terminals, agents, and the druk editor use a hover-guard: **drag the header to
  move, dwell on the body to type**. Dragging the body can enter text instead of
  moving the node. Use the header to reposition.
</Callout>

## Resize nodes

Select any node to show subtle resize handles and a faint outline, then drag a
corner to resize it. Terminals, editors, browser nodes — they all resize.
The size you set is **remembered**: switch projects or restart the app and
each node comes back where you left it, at the size you left it.

## Select and delete

- Click a node to select it.
- Drag in empty space to **box-select** multiple nodes.
- Press **Delete** or **Backspace** to delete selected nodes. Deleting a
  terminal also kills its session, so only delete nodes you no longer want.

## Undo / redo

- **Ctrl+Z** — undo the last layout change.
- **Ctrl+Shift+Z** — redo.

Undo tracks the layout. It pauses while you type in an input or terminal, so
it doesn't fight your shell prompt.

## Organize windows

The **organize** button in the toolbar (next to the settings cog) tidies the
canvas with one click. It has no dropdown — each click advances to the next
layout, cycling in order:

1. **Cascade** — every window stacks on one diagonal, so all the title bars
   stay reachable. Sticky notes align in a row along the top.
2. **Flat** — all windows arrange side by side inside the area you are
   currently looking at, starting at the top-left of your view; when they
   would run past the edge of the view they wrap to a new row below, and the
   canvas zooms out so the whole layout is visible. Stickies get their own row
   above the windows.
3. **Restore** — puts everything back how it was before you started
   organizing. The original arrangement is remembered across layouts, so
   cascade → flat → restore lands you back where you began. After a restore,
   the next organize starts a fresh cycle.

<Callout type="info" title="Organizing is undoable and persisted">
  Each organize is a single undo step (**Ctrl+Z** takes it back), the new
  layout is saved with the project, and group frames are left untouched —
  their children move with them.
</Callout>

## Link nodes together

Nodes can be connected with **links** — edges that pass content between a
source node and a target node (write a terminal's output to a file, feed an
editor's content into a chat, forward an agent's output to another machine).
When you select a node, small link handles appear on its sides: drag from the
right edge of one node to the left edge of another to connect them, then click
the edge to configure what it does. Links are saved with the project. See
[Node links](/docs/node-links).

## The right-click menu

Right-click on the canvas or a node for the context menu. Actions are grouped
into three sections:

- **Open agent** — click Claude Code, Codex CLI, Antigravity, Grok, or OpenClaude
  directly to launch it. Each entry has a small monochrome logo or monogram.
- **Create** — Terminal, Sticky note, Editor, Browser, Chat, Diff, and Druk
  editor add their corresponding nodes to the active project.
- **Selection** — actions for the selected nodes or the node under the cursor:
  Group selection / Ungroup, Close, and agent-specific actions. A2A send to
  peer forwards output to another machine; Claude nodes also offer Branch
  session, Resume session in new node, and links to other agents.

Use **↑ / ↓** to move through actions, **Home / End** to jump to the first or
last action, and **Enter** to activate it. **Escape** or clicking outside closes
the menu. Near a window edge the menu moves into view; in a short window it
scrolls so every action remains reachable.

See [Agents](/docs/agents) and [Agent-to-agent](/docs/a2a) for agent actions.

## The project sidebar

Hover a canvas edge to slide out the project panel — use the dock icon to flip
it to the other side and the pin to keep it open. It's a VS Code-style sidebar
with three sections:

- **Explorer** — the project tree and your open tabs; click a file to open it
  in an editor node. Dotfiles, `.git`, and `node_modules` are hidden.
- **Source control** — git for the active project: the current branch, remote,
  `git push` / `git pull`, and recent history. Source control lives here, so the
  old settings-menu shortcut to it was removed.
- **Plugins** — placeholder (coming soon).

## The settings cog

The **cog** button in the toolbar (top-right) opens **Settings** directly — a
full-width sheet over the canvas, with a grouped sidebar: **Basics** (General,
Appearance, Model settings, Browser), **Agent capabilities** (Skills, Hooks,
Commands, Agent accounts, A2A peers) and **Data and statistics** (Usage, Cloud &
backup, Connections, Updates). Source control lives in the sidebar, so the cog
is a plain one-click path to settings, with no dropdown menu. Right next to it
sits the **organize** button — see [Organize windows](#organize-windows) above.
Every page is listed in [Settings](/docs/settings).

## Arrange it your way

Layout is the product. Spread terminals across the canvas, group related work,
zoom out to see the whole set of running sessions, and zoom in to work. A
spatial layout beats a tab bar you forget.
