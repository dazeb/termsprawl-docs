termsprawl is a **spatial terminal manager for Linux**. Instead of stacking
sessions into tabs you lose track of, it lays them out on one infinite
pan/zoom canvas. Real terminals, editors, and AI agents live as nodes you drag
where you want them — and they stay there, session intact, across restarts.

Everything you run lives inside a real shell. Each terminal is a genuine PTY
inside a persistent `tmux` session, so closing a project or the app detaches
the shells instead of killing them. Reopen and your work is exactly where you
left it.

termsprawl is **Pre-1.0 · actively maintained**. It is usable as a daily
driver and MIT-licensed, but the project file format and internal interfaces
can still change between minor releases — that is what pre-1.0 means here, not
a warning label.

## What it is not

This is not a tab-style terminal multiplexer. It is a **canvas**: you decide
where every terminal, note, editor, and agent lives, zoom out to see the whole
set of running things, and zoom in to work. The spatial layout is the feature.

## A quick tour

A termsprawl window is one **project** at a time, opened as a tab. Inside:

- The **toolbar** holds the brand, the project tabs, the organize-windows
  button, the settings cog, and the app version.
- The **canvas** is an infinite dot-grid surface. Drag nodes around, pan the
  empty space, and zoom.
- A **project** is a folder. Create one, and termsprawl opens a shell in it.

Start with [Get started](/docs/getting-started), or jump straight to a topic
from the sidebar.
